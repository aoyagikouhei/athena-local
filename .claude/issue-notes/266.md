## 実測の手順

- スクリプトのパス: `tools/measure/unquoted-ddl.sh`（`ROUND=13` を追加。ROUND=1〜12 の挙動は変えていない）
- 実行コマンド（S3 Tables のみ。連携カタログは任意）:
  ```
  tools/dev.sh OUTPUT=s3://your-bucket/prefix/ DB=your_db ROUND=13 \
    S3TABLES_CATALOG=s3tablescatalog/your-bucket S3TABLES_NS=your_ns \
    FEDERATED_CATALOG=your_federated_catalog \
    bash tools/measure/unquoted-ddl.sh
  ```
  連携カタログの代わりに、自分のアカウントの Glue を指すデータカタログを作って測るとき:
  ```
  tools/dev.sh OUTPUT=s3://your-bucket/prefix/ DB=your_db ROUND=13 \
    S3TABLES_CATALOG=s3tablescatalog/your-bucket S3TABLES_NS=your_ns \
    CREATE_GLUE_CATALOG=1 \
    bash tools/measure/unquoted-ddl.sh
  ```

- 必須の環境変数: `OUTPUT`・`DB`
- 任意の環境変数:
  - `S3TABLES_CATALOG`・`S3TABLES_NS`（無ければ T 群の `t0s`・`t1s`・`t2s`・`t7s`・`t9s`、U・V・W 群全部、

    `GLUE` 型のデータカタログ `athena_local_probe_266_<乱数>cat` を作って連携カタログの代わりに使う）
  - どちらも無ければ X 群は `xc` だけ測り、`x1`〜`x4` は未測定として残る
  - ほかは既存と同じ `CATALOG`・`REGION`・`OUT_DIR`・`POLL_TIMEOUT`・`RETRY_MAX`・`RETRY_DELAY`
- 出力先: `${DEV_HOST_HOME:-$HOME}/athena-unquoted-ddl-measurements/run-<日時>/`
- 本物への呼び出し回数の見込み（StartQueryExecution）: 19（S3TABLES_* も連携カタログも無し）／55（S3TABLES_*
  のみ）／22（連携カタログのみ）／59（両方あり）。preflight 2 + 常に投げる T 群 11・Y 群 5・X 群の `xc` 1 +

## 実測の結果

ROUND=13（2026-09-26 UTC 22:15、生データ `$HOME/athena-unquoted-ddl-measurements/run-20260926-221348`）。
S3TABLES_* あり・`CREATE_GLUE_CATALOG=1`（自分のアカウントの Glue を指す GLUE 型のデータカタログ
`<GLUE_PROBE_CATALOG>` を作って x1〜x4 に使い、最後に削除できた）。StartQueryExecution は 60 回
（見込み 59 + 受理された vc1 の DROP 1）。受理されたのは vc1 だけで、その場で DROP した（SUCCEEDED）。
ROUND=14（2026-09-26 UTC 22:36、生データ `$HOME/athena-unquoted-ddl-measurements/run-20260926-223637`）。同じ条件で
データカタログを作り直し、最後に削除できた。StartQueryExecution は 28 回（見込み 22 + 受理された z0・z0b・z0c・z2・z3・z4
の DROP 6）。受理されたものはすべてその場で DROP した（SUCCEEDED）。

| 項目 | 文（Context） | 本物 |
|---|---|---|
| t0〜t10 | `CREATE [EXTERNAL] TABLE [IF NOT EXISTS] nosuchcatalog266.<db>.<t> [(n int)] [COMMENT・PARTITIONED BY・CLUSTERED BY・ROW FORMAT SERDE・STORED AS・TBLPROPERTIES の 1 つ／全部] LOCATION '..'`（既定） | 11 件すべて開始時に `Catalog 'nosuchcatalog266' does not exist`（DATACATALOG_NOT_FOUND） |
