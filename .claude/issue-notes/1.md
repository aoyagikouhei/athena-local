## 調査結果の要点（Step 3）

ファイル名の決定は実装済みで、足りないのは中身を書く処理だけ。

- `src/results.rs` の `ResultFile::of` は、CTAS でない `CREATE`、`DROP`、`SHOW` などを `Text` に落とす。`path` は `<id>.txt` を返す。つまりパスの生成はできている。
- `src/operation.rs` の `write_result` にある `location.file != ResultFile::Csv` の分岐が、`.txt` を書かせない唯一のガード。実装はここを広げることになる。
- `ResultWriter::put` は `Content-Type: text/csv` を固定で送る。`.txt` に何を送るかは実測して決める。署名付き URL を作って素の PUT を投げる形。
- `Outcome` の中身は文の種類で変わる。`SHOW` は `SELECT` と同じく列と行が入る。DDL は Trino が `updateType` を返すので行は積まれず、列も行も空になりやすい。つまり DDL の `.txt` に何を書くかは Trino の応答からは決まらない。
- 既存テスト `tests/results.rs` の `dml_と_ddl_は何も書かず_ファイル名だけ本物に合わせて返す` が、今の「DDL では PUT が起きない」を固定している。実装時はこのテストの DDL の部分を書き換える。
- CSV のバイト列は `src/results.rs` のユニットテストと `tests/results.rs` の両方で、実測した文字列リテラルと突き合わせて固定している。`.txt` も同じ形で固定する。
- `src/config.rs` の `ResultsMode` は `none` と `s3` だけ。`.txt` を書くのは `s3` のときに限る。
- 行数は `src/results.rs` が 372 行、`src/operation.rs` が 556 行。CLAUDE.md の「実測していない振る舞いは推測で埋めない」と、README と CHANGELOG の更新の約束が今回に効く。
- 中身の組み立ては `convert::all_rows` が担う。列名を先頭行にし、値は文字列にする。列が空か更新件数があるときは行を返さない。`to_csv` はそれをカンマ区切りで囲むだけ。`.txt` 用の組み立ては、この行の並びから作れる。
- `SHOW` と `DESCRIBE` と `EXPLAIN` を偽 Trino に投げるテストは無い。実測結果に合わせて、偽 Trino の応答も新しく作ることになる。
- **判定の食い違いが 1 つある。** `EXPLAIN` は `statement_type` では DML だが、`ResultFile::of` では `Text`、つまり `<id>.txt` になる。`VACUUM` は `Csv` 側に入っているのに `EXPLAIN` は入っていない。意図なのか抜けなのかはコードから読み取れず、テストも無い。実測項目に追加する。

## 実測でつまずいた点（2026-09-16）

同じ失敗を繰り返さないための記録。

- **`aws` が Docker のラッパだった。** マウントされるのは実行時のカレントディレクトリだけ。`aws s3 cp <src> <絶対パス>` はコンテナの中に書いて消え、しかも終了コードは 0 になる。1 回目だけ取得できたのは、出力先が当時のカレントディレクトリの下だったから。対処として、取得は `aws s3 cp <src> -` で標準出力に流し、リダイレクトはシェルが行う。`aws athena ...` の JSON が毎回取れていたのは、同じくシェルがリダイレクトしていたため。
- **データベース名が実在しなかった。** すべての `SHOW` が Entity Not Found で落ちた。対処として、最初に `SHOW TABLES` で疎通を確かめ、失敗したら `SHOW DATABASES` の一覧をファイルに残す。
- **テーブル名が実在しなかった。** 対処として、`SHOW TABLES` の結果からテーブル名を取り、指定が無いか一覧に無ければ 1 件目を使う。
- 名前は端末に出さず、ファイルに置くだけにしている。

3 回目で再現できたこと。`SHOW TABLES`、`SHOW DATABASES`、`EXPLAIN` は `.txt` と `.txt.metadata` の両方が置かれ、`CREATE DATABASE` と `DROP DATABASE` は 0 バイトの `.txt` だけで `.metadata` は無い。中身は未取得。
