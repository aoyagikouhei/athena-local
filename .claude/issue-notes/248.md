### 読み取れる規則（実装への含意）
- S3 Tables の Context の LOCATION 付き CREATE TABLE は、Hive の句（COMMENT・CLUSTERED BY・SERDE・DELIMITED の各句・
  TBLPROPERTIES の組数・STORED AS）とバッククォートの表名によらず `Table location` の開始時エラーになる。
  ただし **列に Trino の型の書き方（`row(...)`）があると、Hive の読み方ではなく Trino の構文エラー**（`LOCATION` で
  mismatched input）になる。#208 の既定の Context・LOCATION 無しの `row(a int)` は NV だったので、Context と LOCATION の
  有無で読み方が変わる点に注意（別経路）
- LOCATION の無い EXTERNAL は、名前の形・後ろの句によらず `External keyword` の開始時エラー
- 1 部目が実在しないカタログの 3 部 + LOCATION は、Context（既定・S3 Tables）と綴りによらず開始時の
  `DATACATALOG_NOT_FOUND`（`Catalog '<書いた名前>' does not exist`）。実在するカタログのときは未測定（s14）
- STORED AS（PARQUET・ORC）で LOCATION 無しは開始でき FAILED（2 / 1200）。結果ファイルは置かれない。LOCATION 付きの
  STORED AS は `Table location` が先に出る
