### 決め手 2: 文言の規則（Trino が構文として受ける文だけ。Trino が弾く文は Trino の文言がそのまま出る＝判定の順は「構文チェック → この拒否」）
| 文 | 名前の最初の部分が引用符付き | 最初の部分が無引用で後ろが引用符付き（`db."t"`） |
|---|---|---|
| DESCRIBE・DESC・ALTER TABLE（Trino が受ける操作） | `line L:C: no viable alternative at input '<文の最初の語 … 最初の引用符付きの部分の終わり>'`（例 `'DESCRIBE "t"'`・`'ALTER TABLE "nope"'`） | `line L:C: no viable alternative at input '<名前の始まり … 引用符付きの部分の終わり>'`（例 `'db."t"'`。ALTER は未実測） |
| SHOW COLUMNS FROM／IN・DROP TABLE［IF EXISTS］ | `line L:C: mismatched input '<最初の部分>' expecting {…}`（一覧は 5 件とも同一、#200 の DROP とも同一） | 同上の no viable alternative |
| SHOW CREATE TABLE | `Queries of this type are not supported`（位置なし。末尾の空白があっても同じ） | 同じ |
| DESCRIBE の S3 Tables（最初の部分が別カタログ） | `Unsupported DDL with 2 catalogs`（位置なし） | — |
- C は引用符付きの部分の開始位置 + 1（1 文字目が 1）。先頭の空白は数えない（`  DESCRIBE "t"` → `1:10`）、先頭のコメントは数える（`/* c */ DESCRIBE "t"` → `1:18`。input にはコメントを含めない）、改行の後は `line 2:1`（`DESCRIBE\n"t"`）。空白 2 つはそのまま数え input にも残る。小文字のキーワードも同じ規則で input は元の綴り
- input の中の改行は文字どおりの `\n`（バックスラッシュと n）で出る
### ほかに分かったこと（範囲外）
- 本物は無引用の `ALTER TABLE t ADD COLUMN m int`（Trino の綴り）を開始時に弾く。docs/ddl.md:48・caveats.md:94-105 は athena-local で ADD COLUMNS の行に届く書き方として `ADD COLUMN` を勧めている（本物では弾かれることが書かれていない）
- 本物はバッククォートの名前（`` DESCRIBE `t` ``・`` DROP TABLE `t` `` など）を受ける。athena-local は Trino が構文エラーにする
- 本物は無引用の `MSCK REPAIR TABLE t` を受ける（MSCK_REPAIR）。athena-local は Trino に MSCK が無いので弾く

### 方式
- 新しいモジュール `src/operation/quoted_names.rs`（純関数。I/O 無し）: `rejection(query: &str, is_alias: impl Fn(&str) -> bool) -> Option<String>` が、本物が開始時に弾く形なら文言を返す
- 呼び出し: `execution.rs` の構文チェック（:73-77）の**直後**。Some なら `invalid_request_with_code(message, "MALFORMED_QUERY")`。Trino が構文エラーにする文（`ALTER TABLE "t" ADD COLUMNS`・`SET TBLPROPERTIES`・`MSCK`）は本物も Trino の文言を返したので、構文チェックを先にする（実測の決め手 2）。`is_alias` は `app.config.catalog_map.contains_key`
- 対象の文と名前（`athena_sql::Cursor` の `keyword` と `qualified_name` で読む。先頭のトリビアは Cursor が読み飛ばす）:
  | 文 | 名前の前のキーワード | 最初の部分が引用符付き | 後ろの部分だけ引用符付き |
  |---|---|---|---|
  | DESCRIBE・DESC | `DESCRIBE`／`DESC` | 別名なら `Unsupported DDL with 2 catalogs`、それ以外は no viable alternative（input は文の最初の語から） | no viable alternative（input は名前の始まりから） |
  | ALTER TABLE | `ALTER TABLE` | no viable alternative（文の最初の語から） | 同上（名前の始まりから。未実測の一般化） |
  | SHOW COLUMNS | `SHOW COLUMNS FROM`／`IN` | mismatched input '<最初の部分>' expecting {EXPECTING} | no viable alternative（名前の始まりから） |
  | DROP TABLE | `DROP TABLE`［`IF EXISTS`］ | 同上 mismatched | 同上 |
  | SHOW CREATE TABLE | `SHOW CREATE TABLE` | `Queries of this type are not supported` | 同じ |
- 位置 `line L:C`: 引用符付きの部分の開始位置を、先頭の ASCII 空白を除いた SQL で数える（L = それまでの改行の数 + 1、C = 行頭からの文字数 + 1）。input の中の改行は文字どおりの `\n`（R3 で `\r`・`\t` は外した）
- EXPECTING は実測の生データ（x-n1.start.err）から機械的に取り出した定数。転記後に生データと diff で突き合わせる
