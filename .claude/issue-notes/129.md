## 設計判断

Step 4 でユーザーに確認済み（2026-09-23）:
1. **資格情報は環境変数で渡す。** 実測のときだけホストのシェルで `AWS_ACCESS_KEY_ID` などを export してから `tools/dev.sh` を呼ぶ。toolbox にはホストの aws ラッパと同じ 7 つ（`AWS_ACCESS_KEY_ID AWS_SECRET_ACCESS_KEY AWS_SESSION_TOKEN AWS_DEFAULT_REGION AWS_PROFILE AWS_CONFIG_FILE AWS_SHARED_CREDENTIALS_FILE`）を、**設定されているときだけ**渡す。ホストの `~/.aws` があれば読めるようにもする（両対応）。
2. **実測の出力先はホストの `~`**（`~/athena-*-measurements`。過去の記録と同じ場所）。dev にホストのホームを同じパスでマウントし、tools/measure の既定の出力先をホストのホームにする。docker.sock を渡しているので権限上の差は無い。`rm -rf .toolbox` で生データが消えない。
3. **mc を toolbox に入れる**（ダイジェスト固定の `COPY --from=quay.io/minio/mc@sha256:...`。`:latest` だと toolbox のタグが変わらないまま中身が変わる）。足場 7 ファイルの使い捨てコンテナを直呼び（`mc alias set local http://minio:9000 ...`）に置き換え、`MC_NETWORK` の取得と 6 箇所のガードを消す。python-clients の trace は toolbox 内のバックグラウンドプロセス + ファイル読みに置き換える。
4. **cargo と docker build を toolbox に寄せる。** CLAUDE.md のコマンド節、development.md、`.claude/skills/release/SKILL.md`（リポジトリの Skill）の既定を `tools/dev.sh cargo ...` にする。ホスト直でも動くことは 1 行で残す。CI（ci.yml）はホストランナーで直に cargo のまま（#130 で扱う）。

統括役の決定（Plan の open な点。工学判断）:
5. `minio-init` の `quay.io/minio/mc:latest` はそのまま（MinIO 本体も `:latest`。サービスのイメージは足場の結果に効かず、固定すると版上げで 2 か所直すことになる）。toolbox の mc だけダイジェスト固定。
6. `opaque-metadata-form.sh` は toolbox 化の対象から外し、ホストで流すものとして残す（aws を呼ばず、保存済みの実測データを検算するだけ。ホストには xxd がある。削減レビュー）。
7. Docker ラッパを理由にした `aws s3 cp <src> -` のコメント 16 本以上は触らない（「aws が Docker のラッパだと…」という条件付きの記述で誤りではなく、実装は toolbox でも無害）。CLAUDE.md の「tools/measure は #129 まではホストのまま」だけ直す。
8. `command -v aws` の事前確認は増やさない（toolbox が唯一の供給源で、無ければ全部が同じように落ちる）。
9. compose.yml の `environment:` の値無しキー（`AWS_ACCESS_KEY_ID:`）は「ホストで未設定なら渡さない、設定されていれば渡す」（Plan が `docker compose config` で確認）。`${VAR:-}` は空文字が渡るので使わない。`AWS_SHARED_CREDENTIALS_FILE` / `AWS_CONFIG_FILE` は `${VAR:-${DEV_HOST_HOME}/.aws/...}` の既定（ユーザーの明示が勝つ。ネストした補間を Plan が config で確認）。
10. 実測の出力先は `DEV_HOST_HOME`（tools/dev.sh が export し、compose.yml の dev の environment に **`DEV_HOST_HOME: ${DEV_HOST_HOME}` で引き継ぐ**。#128 の DEV_* と同じ並び）。スクリプトは `${OUT_DIR:-${DEV_HOST_HOME:-$HOME}/athena-...}`（ホスト直なら従来どおり）。別名の `MEASURE_HOME` は作らない（削減レビュー: 同じ値に 2 つの名前）。toolbox の `HOME`（`.toolbox/home`。cargo・pip・JDBC のキャッシュ）は変えない。jdbc 系の `DRIVER_CACHE_DIR` も変えない。
11. awscli v2 は `awscli-exe-linux-<arch>-2.37.0.zip` で版を固定し、`uname -m` で選ぶ。
