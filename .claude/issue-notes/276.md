   `Query type not supported by Athena Iceberg at this time`（2/1200）、`DESCRIBE EXTENDED` は `EXTENDED keyword is not supported for Iceberg tables.`（2/1100。#275 にも効く）
2. **ビュー・無い表**: 群 A の 6 形とも H と同じ ParseException（今は Hive 表だけ失敗させ、ほかは Trino に送っている）
3. **位置**: 群 B の各位置は、`/` の位置の ParseException（ALTER の REPLACE COLUMNS・CHANGE COLUMN・RENAME TO は ErrorMessage が `Query type not supported by DDL engine.`、

4. **字句**: `>=`・`<>`・`==` も 2 文字（今は `<=`・`!=` だけ 2 文字）。閉じていない引用符は、文の後ろ（後ろのコメントの中も含む）に `'` があればそこまでを 1 つの文字列として読む
5. **awsdatacatalog. 付きの DROP COLUMN・RENAME TO**（コメントの有無・位置によらず）: 受け取った文で `no viable alternative at input '<表名の直前まで>'`、位置は表名の先頭、2/1006、Query は受け取ったまま。
   athena-local は落とした後の文で数えている（#256 の項目もこれ）
6. **awsdatacatalog. 付きの ADD COLUMNS・SHOW CREATE TABLE・MSCK・DESCRIBE**: 位置は落とした文で数え（DESCRIBE は DB まで落とした文）、Query も落とす
7. **Query**: DESCRIBE EXTENDED／FORMATTED はビュー・無い表でもコメント越しに DB が落ちる
8. AthenaError の型: ALTER の REPLACE COLUMNS・CHANGE COLUMN・DROP COLUMN・RENAME TO は 2/1006、ADD COLUMNS・SHOW CREATE TABLE・MSCK・DESCRIBE は 1/1003
