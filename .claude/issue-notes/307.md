## 計画（小規模経路・1 フェーズ）

- 経路の事実: 修飾子の無い `DESCRIBE t`／`DESC t` は `describe_extended::parse` が対象外（describe_extended.rs:71-73）なので
  describe_start を通らず、`background_execution::run`（:219）→ `execute_bound` → `utility_rows::reshape` → `describe_iceberg_rows`。
  Explore 2 本目の「plain DESCRIBE は describe_start の `(Suffix::None, _)` の腕を通る」は誤り（その腕は FORMATTED 用）として落とした
- 変更:
  1. `type_spelling::iceberg`: 最上位の `timestamp(p) with time zone` → `timestamp`（済み・green）
  2. `failure/describe.rs`: `Failure::describe_iceberg_unsupported_column_types()`（USER・1100・`Table has unsupported column types`）
  3. `utility_rows.rs`: `has_unsupported_iceberg_column(rows) -> bool`（Trino の DESCRIBE の `Type` が `uuid` か `time(p)`。最上位だけ）
  4. `background_execution.rs`: `run()` の Err を `RunError { Engine(QueryError), NoResultFile(Failure) }` にし（`From<QueryError>`）、
     Iceberg の Describe の行に 3 が当たれば `SHOW CREATE TABLE` を投げる前に `NoResultFile` を返す。`spawn_query` は
     `NoResultFile` なら `write_failure` を呼ばずに `finish(Err(failure))`
- 触らない: FORMATTED（describe_run 経由）・SHOW COLUMNS・入れ子の中（未実測。unmeasured と caveats に書いた）
- テスト: tests/describe.rs に Iceberg の表で `Type` が `time(6)`・`uuid` の DESCRIBE → FAILED 2/1100・文言・`s3_puts` 空・
  `SHOW CREATE TABLE` を送らない。対照: `timestamp(6) with time zone` の列は SUCCEEDED で `timestamp`、Hive の表の `uuid` 列は今どおり成功
- 壊す候補: (a) 3 の判定を常に false (b) `NoResultFile` でも write_failure を呼ぶ (c) 1 の分岐を消す
- 先行できる作業: docs（measurements・unmeasured・caveats）は済み。CHANGELOG は実装と同時
