## 調査済みの材料（implement-issue への引き継ぎ）

- 判定は 2 箇所。`src/operation.rs` の `words()`（`split_whitespace` + 先頭の `(` 除去 + 大文字化）が `statement_type` / `substatement_type` を支え、`src/results.rs` の `ResultFile::of` が独自に同じ形の単語列を作る。どちらのコメントにも「先頭のコメントは考慮しない」と書いてある。
- `src/catalog.rs` に共有できる字句処理がある: `comment_end`（`--` と `/* */` の終わりを返す。閉じていなければ末尾）と、空白＋コメントを飛ばす `next_is_dot` の走査。いまはどちらも private。先頭のコメントと空白を飛ばす関数はこの `comment_end` を使って書ける。
- 「SQL の本文は書き換えない」（CLAUDE.md）ので、Trino に送る SQL は従来どおり。判定に渡す前の読み飛ばしだけにする。
