## 設計判断
- D1（Step 4、ユーザー）: (A) 無引用の `ALTER TABLE IF EXISTS ...` を開始時に弾く
- D2（Step 4、ユーザー。推奨は「弾かない」だったが「弾く」を選択）: (B) `ALTER TABLE t ADD COLUMN m int`（単数）を開始時に弾く。athena-local で ADD COLUMNS の挙動に届く書き方は無くなる
- D3（Step 4、ユーザー。推奨は「弾かない」だったが「弾く」を選択）: (C) CTAS でない場所の無い `CREATE TABLE` を開始時に弾く
- 弾くのは実測した形だけ（#204 の D2 と同じ方針。文言を推測で埋めない）
- D4（実測後、ユーザー。推奨どおり）: `ALTER TABLE IF EXISTS ... ALTER COLUMN` は本物の Trino 形の文言（R-A2）で弾く
- D5（実測後、ユーザー。推奨は「別 issue に起票」だったが「この issue で全部弾く」を選択）: IF EXISTS の無い Trino 専用の ALTER 6 形（RENAME COLUMN・SET PROPERTIES・EXECUTE・ALTER COLUMN・DROP COLUMN IF EXISTS・SET AUTHORIZATION）も実測の文言で弾く。docs が OPTIMIZE の代わりに案内している `ALTER TABLE ... EXECUTE optimize` も使えなくなる
- D7（ラウンド 2 の後、統括役。ユーザーが「追加で実測する」を選び、結果が一般化を支えた）: 型名は識別子なら区別しない（存在しない `foo` も No location）。型の後ろの語は NV(その語)（NOT・with・precision・day の 4 語で確認。NOT 専用の分岐は要らない）。`LIKE` は列の名前として読む（1 部は No location、2 部以上は型の後ろの `.` で NV(`.`)）ので専用の分岐を置かない。`型名(` の中の最初の語は型名によらず NV(その語)（row・array・map・ROW で確認。型名は構文で区別されないので一般化）
- D6（実測後、ユーザー。推奨どおり）: CREATE TABLE は実測した形を全部弾く（Hive で読める形は No location、WITH・NOT NULL・row/array/map は構文の文言）。実測していない形（`LIKE` の 1 部の名前など）は今までどおり実行。athena-local で素の表を作る書き方は無くなる（CTAS は残る）

### ALTER（フェーズ 1）
- `table_name_start(sql, ["ALTER","TABLE"])`（`target_table.rs:77-86`。IF EXISTS を読み飛ばす）→ `Cursor::qualified_name()` → 後ろの語を `Cursor::keyword` で読む（`classification.rs:113-161` の `alter_table_action` と同じ読み方。判定の関心が違うので関数は分ける）
- IF EXISTS あり: 後ろが ADD・DROP・RENAME → R-A1 NV(EXISTS)（input は文の最初の語から EXISTS の終わりまで）／ALTER → R-A2（位置は 2 つ目の ALTER）／それ以外 → None（Trino 482 が構文エラーにするので届かない）
- IF EXISTS なし: `ADD COLUMN`（`COLUMNS` は `Cursor::keyword` の語の境界で一致しない。`cursor.rs:32-51`）→ R-B1 NV(COLUMN)／`RENAME COLUMN` → `missing 'TO' at 'COLUMN'`／`SET PROPERTIES` → NV(PROPERTIES)／`SET AUTHORIZATION` → NV(AUTHORIZATION)／`EXECUTE` → NV(EXECUTE)／`ALTER` → Trino 形（Expecting 6 語）／`DROP COLUMN IF EXISTS` → `mismatched input 'EXISTS' expecting {<EOF>, '.'}`（位置は EXISTS）／`DROP COLUMN m`（b19）ほかは None
- Trino 形の文言の `'X'` は元の綴りのまま入れる（小文字は未実測。Trino のパーサはトークンの原文を出す）

### CREATE TABLE（フェーズ 2。ラウンド 2 の結果で D7 に改めた）
- `substatement_type(query) == Some("CREATE_TABLE")`（CTAS を除く。`classification.rs:58-67`・`results.rs:97-110`）かつ `table_name_start` が `["CREATE","TABLE"]` か `["CREATE","TABLE","IF","NOT","EXISTS"]` に一致（`CREATE OR REPLACE TABLE` はここで外れる）。名前の後ろに `(`、無ければ None。列 0 個 → None
- 列: 列の名前（無引用の識別子。`LIKE` もただの列の名前として読む。引用符付き → None）→ 型 → 型の後ろ
- 型: 識別子（型名は区別しない）。後ろが `(` なら、中の最初のトークンが数字なら `)` まで数字・`,`・空白だけを読み飛ばす（他の文字 → None）、識別子なら R-C4 NV(その語)、それ以外 → None。後ろが `<` なら深さを数えて `>` まで読み飛ばす（中身は識別子・数字・`,`・`:`・`<>`・空白だけ。他は None）
- 型の後ろ: `COMMENT '..'` を読み飛ばし、`,` → 次の列／`)` → 列の終わり／識別子（`NOT`・`with`・`precision`・`day`・`INCLUDING` など）→ NV(その語)／`.` → NV(`.`)／それ以外 → None
- `)` の後: [`COMMENT '..'`] → 終わり → R-C1 No location／`WITH (` → NV(`(`)／それ以外 → None
