# #283 COLUMN_NOT_FOUND の文言に本物の「or requester is not authorized to access requested resources」を付けるか、ほかの文で測って決める

## 出どころ

- issue #283。#272 の先行実測（2026-09-27、`tools/measure/unquoted-ddl.sh` の ROUND=18、生データ
  `$HOME/athena-unquoted-ddl-measurements/run-20260927-000528`）で、#272 の範囲（接尾辞と位置）の外に
  見つけた差が根拠。
- 既知の事実（#272 の先行実測。CTAS が p2・p3・p4・w3、INSERT が i1）:
  本物の COLUMN_NOT_FOUND の文言は
  `Column '<名前>' cannot be resolved or requester is not authorized to access requested resources`
  （2/1006）だった。手元の Trino 482 は `Column '<名前>' cannot be resolved` まで（ここで文言が切れる）。
  athena-local は Trino の文言のまま返すので、本物とは食い違う。
- 既知の事実（2026-09-17 の実測。`tools/measure/failed-query-results.sh`、生データ
  `$HOME/athena-failed-measurements/run-20260917-214013` の `failed-delete-no-column`）:
  DELETE の WHERE に無い列（`DELETE FROM <Iceberg> WHERE no_such_col = 1`）も同じ文言・同じ 2/1006 だった。
  DELETE はこの実測で測り済みなので、このラウンドの項目には入れない。
- 継承できる事実（issue 本文より）:
  - 失敗の文言は `src/failure.rs` の `Failure::from_query_error`（`"{name}: {message}"`）で作る。
  - #272 は CTAS・INSERT の接尾辞（` You may need to manually clean the data at location '...' before
    retrying. Athena will not delete data in your account.`）と `line 6:3` の位置の差だけを扱い、
    COLUMN_NOT_FOUND の文言そのものの差（`cannot be resolved` で終わるか、追加の一文が付くか）は
    範囲外として #283 に起票した（SELECT・EXPLAIN・CREATE VIEW などほかの文で同じ文言かが未測定だったため）。
  - `docs/dev/measurements/` を COLUMN_NOT_FOUND で grep しても、CTAS・INSERT（#272）と DELETE の WHERE
    以外の記録は無い。UPDATE の SET に無い列を書いた場合は別の文言
    `The UPDATE SET target column <名前> doesn't exist`（`docs/dev/measurements/result-files.md:370`）で、
    COLUMN_NOT_FOUND とは別物（このラウンドの UPDATE の項目は SET の右辺・WHERE・SET の対象でない列を使う
    ことで COLUMN_NOT_FOUND 側を引く）。
- 推奨する経路（issue 本文より）: このラウンド（request-measurement）→ 文言が全項目で同じ形（`cannot be
  resolved` の直後に本物の一文が付く）なら、quick-implement で `COLUMN_NOT_FOUND` の文言の後ろに定数の
  一文を足すだけで足りる見込み。

## 手元の経路の確認（2026-09-27、統括役。実測の待ちの間）

compose の Trino 482（`athena-local-trino-1`）に、表を使わない形で同じ種類の文を投げた。どれも
`line L:C: Column '<名前>' cannot be resolved`（COLUMN_NOT_FOUND）になり、athena-local の経路で同じ失敗に届く。

| 文 | Trino 482 |
|---|---|
| `SELECT nosuch283`・`SELECT nosuch283 FROM (VALUES 1) AS t(n)`・`SELECT nosuch283 FROM system.runtime.nodes` | `line 1:8: Column 'nosuch283' cannot be resolved` |
| `SELECT transform(ARRAY[1], x -> y)` | `line 1:33: Column 'y' cannot be resolved` |
| `SELECT NOSUCH283 ...`・`SELECT "NoSuch283" ...` | `Column 'nosuch283'`（引用符付きでも小文字で出る） |
| `EXPLAIN SELECT nosuch283 ...`・`EXPLAIN ANALYZE SELECT nosuch283 ...` | 位置は SELECT の中の列（1:16・1:24） |
| `... GROUP BY nosuch283` | 位置は GROUP BY の列 |

本物の c18（引用符付き `"NoSuch283"`）で名前の大小が Trino と同じかは、実測の結果と突き合わせる。
