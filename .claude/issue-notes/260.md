### 読み取れる規則（実装への含意）
- 無引用の `awsdatacatalog.<DB>.<t>` を含む SELECT・INSERT は、Context の Catalog が S3 Tables・実在しないカタログ・省略のどれでも成功する
  （#214 で測った「実在しないカタログの Context の SELECT」と合わせて、Context の Catalog によらない）。athena-local は Catalog が
  AwsDataCatalog か省略のときだけ置換しているので、**S3 Tables・実在しないカタログの Context でも置換する**よう広げる候補
- 部品に引用符付きを含む形（o6・o7）と 4 部の列の参照（o8）も成功する。athena-local は無引用のちょうど 3 部だけを置換しているので、
  **引用符付きの部品・4 部の列の参照にも広げる**候補（書き換えの条件の一覧と `docs/configuration.md` の約束に関わる）
- 大文字の `AWSDATACATALOG`（o11）も成功（#246 の大文字小文字によらない扱いのとおり）
