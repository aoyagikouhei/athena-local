### 変更内容

- `ResultFile::FailedText`: `of` は返さない、`path` は `Metadata` と同じ `unreachable!`、`content_type` は `application/octet-stream`。`ResultLocation::failed(&self) -> Option<Self>` は `self.file == Text` のときだけ `Some`（bucket / key は同じ、file だけ `FailedText`）。既存の `Metadata` + `metadata()`（`src/results.rs:29-31`、`:115-121`）と同型。**`ResultFile::of` は触らない**（CLAUDE.md:43 の判定 2 か所を増やさない）。
- `spawn_query` の `Err` 腕（`src/operation.rs:220`）:
  ```rust
  Err(error) => {
      let failure = Failure::from_query_error(&error);
      // FAILED にする前に置く（クライアントは FAILED を見た直後に S3 を読みに行く）。
      write_failure(&app, &execution, &failure).await;
      Err(failure)
  }
  ```
- `write_failure(app, execution, failure)`: `(Some(writer), Some(location))` でなければ return → `cancel.is_requested()` なら return（`write_result:243` と同じ。`QueryError::cancelled()` の経路もここで弾く）→ `location.failed()` が None なら return → `format!("FAILED: {}", failure.reason).into_bytes()` を `put` → `Err` は `eprintln!` 1 行。
- `write_failure` の doc コメントに「`.csv` の PUT 失敗で FAILED になる経路（`write_result`）は通らない」と書く（`write_result:263` にはコメントを足さない）。`eprintln!` は既存と同じ形「…ファイル（.txt）の書き込みに失敗しました。無視します: {reason}」。
- Content-Type の表し方の候補 3 つ（`put` に渡す／`ResultLocation` にフィールド／新バリアント）のうち、決定が `content_type` 1 箇所に残る新バリアントを採る。

### 早期 return の全経路（設計チェックリスト）

`store.get` 失敗・`mark_running` 失敗（投入直後の取り消し）・`Ok` 腕の `write_result` の各 return（`.csv` の PUT 失敗で FAILED になる :263 を含む）は失敗ファイル不要で、新コードに到達しない。`Err` 腕の中では、取り消し・書かないモード・`result_location` None・Csv / Manifest / Table・PUT 失敗のそれぞれで置かない／握りつぶす。**既存 `tests/stop.rs:97` は `statement_delay` の 1 ページ応答なので `run` が `Ok` を返し、`Err` 腕（`write_failure`）に入らない**（`src/trino.rs:87-99`: `nextUri` が無ければ cancel を見ずに `Ok`）。`write_failure` の cancel ガードを通すには `.endless()` でページ境界の取り消し（`src/trino.rs:133-140` の `QueryError::cancelled()`）にする必要がある → Text の endless 版の取り消しテストを足す。

### 直列化・エスケープ境界

`failure.reason` → PUT body は `format!("FAILED: {}", reason).into_bytes()` だけ。平文ファイルでエスケープ規約は無い（本物も生のまま。`to_text` も同じ）。キー・ヘッダにメッセージは入らない。厄介な入力: `line 1:1: スキーマ "no_such"db" が見つかりません\n(ヒント: タブ\tと改行)` をバイト列完全一致 + 末尾改行なしで固定。
