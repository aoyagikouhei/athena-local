### 読み取れる規則（解釈。位置付きの CTAS 31 件がすべて一致する）
本物は CTAS を Trino の SqlFormatter（`formatSql`）で整形し直し、プロパティを 1 つ足した文を実行しているとみられる。整形後の形:

```
1 CREATE TABLE <名前>
2 WITH (
3    <本物が足すプロパティ 1 つ>        ← 利用者の WITH のプロパティ 1 つごとに 1 行増える（p8 は 7 行目、p9 は 8 行目）
4 ) AS SELECT <1 項目>                  ← 項目が 1 つなら同じ行（`) AS SELECT ` の 12 文字の後ろ = 13 桁目。p2・p12）
  ) AS SELECT                            ← 項目が複数なら改行して `  n` / `, s` / `, nosuch272`（前置きの `, `。p3 は 7 行目 3 桁目）
5 FROM
6   <表>                                ← 表は 2 桁の字下げ（3 桁目。p1）
7 WHERE (nosuch272 = 1)                  ← 比較は括弧で包まれる（`WHERE (` の後ろ = 8 桁目。p4）
```

- 括弧の問い合わせ（p6）は `) AS (` の後ろを 3 桁字下げ（表は 7 行目 6 桁目）、WITH 句（p7）は `) AS WITH` / `  c AS (` の後ろを 3 桁字下げ（8 行目 6 桁目）
- `1 + 'a'` は `(1 + 'a')` に括弧が付き、位置は演算子 `+`（13 桁目の `(` から 3 つ右の 16 桁目。p12）
- 受け取った文の改行・空白・先頭のコメント・IF NOT EXISTS・名前の部の数は位置に効かない（整形で消える）。DB の有無も効かない
- INSERT は組み直さない（送った文のままの位置。接尾辞も別）
